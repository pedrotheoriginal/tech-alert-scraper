# Web Scraper de Alertas Tecnológicos 🚀

Um script em Python desenvolvido para automatizar a recolha de títulos e notícias de tecnologia, com foco em extração de dados web e boas práticas de programação.

## 🛠️ Tecnologias Utilizadas
* **Python 3.x**
* **Requests** (para requisições HTTP)
* **BeautifulSoup4** (para análise e extração de dados HTML)

## ⚙️ Como Funciona
1. O script acede a uma página de referência (como o Hacker News).
2. Faz o download e o parsing do código HTML utilizando seletores estruturados.
3. Analisa e imprime os títulos e links dos artigos diretamente na consola de forma limpa e organizada.
